# Решение

## Затраченное время

Время разработки и отдельно время настройки окружения:
- загрузка задания, чтение md/doc задания (docker, а python3 снаружи?), ознакомление c файлами проекта, начальный коммит и далее пауза 
  до того как буду готов заняться ~ 20 мин;
- размышления на тему/анализ конфигов docker compose, сборок php, планирование интеграции с собственной инфраструктурой, анализ возможности добавления слоя nginx
  и необходимости такого шага; планирование добавления xdebug для скорейшего понимания воркфлоу жизненного цикла (ИМХО важное расширение функционала) - 
  помимо анализа непосредственно кода будет ещё инструмет, что может дать больше гибкости в поиске проблем ~ 20мин;  
- развёртывание, сборки (включая время ожидания билдов), перебор вариантов для достижения желаемого (мною) результата ~40мин 

- ошибка 1: причина приблизительно понятна из описания, поиск лучших практик, ознакомление, внедрение после анализа, ручная проверка ~ 50 мин 
- добавление теста, показывающего состояние гонки ~ 20 мин (для проверки поведения в браузере нужен playwright - я не буду ставить и так питон лишний на хосте) 

- ошибка 2: причина - отсутствие проверок RBAC в функционале сохранения состояния, написание теста для эмуляции передачи в форме некорректных данных ~ 25 мин.
